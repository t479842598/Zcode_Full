ZCode 自托管版 v3.16.2-selfhost.9 —— 修复「runtime 空闲回收后被立即重拉」的自激循环，常驻内存从 7.1 GB / 94 进程降到 810 MB / 8 进程。

**根因**

会话泳道（chat lane）引入了 5 分钟空闲回收（`CHAT_LANE_IDLE_TIMEOUT_MS`），用来释放 workspace runtime 及其挂载的 7~9 个 MCP 子进程。但回收后 runtime 会被立刻重新拉起，形成永久自激：

- selfhost.7 加 `ZCODE_TRACE_AGENT_START=1` 插桩（`traceAgentStartCaller`）后抓到两条并发调用栈：`queryConversationCommandsV4`（回收后 +24~32ms，走默认 `start-if-needed`）与 `startModelExecutionClient`（+42~50ms，join-inflight）。
- selfhost.8 加了 30 秒冷却窗口：回收时刻记入 `lastIdleReclaimAtByWorkspaceKey`，`getReadOnlyClient` 的 start-if-needed 分支在窗口内抛 `ZCODE_AGENT_RUNTIME_UNAVAILABLE`。被动查询确实被拦住了。
- 但**写路径不受限**：真正把 runtime 拉回来的是 **draft 预热**。`useDraftRuntimeRebuildGate` 在 `onRuntimeLifecycle("unavailable")` 当场调 `invalidateDraftRuntime`，`draftRuntimeInvalidationVersion` 递增，`useDraftSessionPrewarm` 立即 `reconcile() → startCurrent()` 发 `createSession`，经 `sendConversationCommandV4`（写路径 `getClient`）重启 agent。

**修复**

- 换代门禁改为 stale-only：`unavailable` 只置 `stale: true` 并作废当前预热 binding（`discard()`），**不再递增** `draftRuntimeInvalidationVersion`。hook 去掉 `workspacePath`/`workspaceIdentity` 参数与 store 依赖，改为 `onRuntimeUnavailable` 回调。
- 重建改由发送路径懒触发：`SessionPane` 的 `await waitForDraftSession()` 在 `current.settled && !current.binding` 时就地重建。用户不发消息就不重建，runtime 才真正归零。
- `discard()` 写入的 `blockedInvalidationVersion` 同时挡住 `scheduleRetryAfterFailure` 的自动退避，回收不再触发后台创建。
- 新增 `effectivePrewarmSessionId`：stale 时把已死的预热会话从 `effectiveSessionId` 与 followupMode 同步目标里摘掉，附件留在 `waitingSession` 而不是直撞 `sessionNotFound`。
- reducer 补一处修正：`prewarmSessionChanged` 先判 null/相等，再判 `!rebuilding && !stale`，保证「rebuildTimeout 已解除门禁但 stale 仍在」时迟到的新会话能清掉 stale。

**验证（实机三轮）**

- 纯空闲 30 秒：`idle timeout; reclaiming` 1 次，回收后 agent spawn 调用栈 **0 条**。
- 发一条真实消息：恰好 1 次 spawn（`fresh-start` 与 `join-inflight` 是同一进程的 single-flight 合并），`sendConversationCommandV4 OK (748.8ms)`；8 秒后回收，**0 spawn**；UI 三次退避后停在「重新连接」，点击后恰好 1 次 spawn 并恢复对话。
- 带长任务（`sleep 60`）：任务在跑时 **90 秒不被回收**（阈值仅 8 秒，`hasActiveWork` 门禁生效），结束回收后 **0 spawn**。
- 内存：main rss 在 316~323 MB 间波动不增长；ZCode 相关总量由修复前峰值 7150 MB / 94 进程降到 810 MB / 8 进程。

**同时包含（selfhost.2 ~ .8）**

- 外观自定义：配色预设（极光紫 / 深海蓝 / 暖沙金 / 玫瑰粉 / 森林绿）、强调色覆盖、背景图（本地图片与 http(s)/data 地址）、填充方式、遮罩浓度、模糊半径、表面不透明度，设置页「自定义外观」卡片，按窗口独立生效并广播同步。
- 中继可靠性：修复物理帧超限（`encodeRelayFrames` 复用共享编码器、seq 逐片 +1），实测手机端 90 秒仅 1 次 socket、0 次重连，最长物理帧 1048569 B；agentWarmupTargets 被过滤成空时的 relay 兜底与 skipped 日志。
- 任务状态同步：`relayLiveTaskStatus` / `hostWorkspaceTaskTracker` 活动任务叠加到远控状态。
- runtime 空闲回收本体（`CHAT_LANE_IDLE_TIMEOUT_MS` 默认 5 分钟、双来源活体门禁、`ZCODE_CHAT_IDLE_TIMEOUT_MS` 排障开关）。
