# Zcode_满血_青棠 v3.14.3 — 内置无限四代内核 + 限时额度可直接领取

版本号与官方稳定线对齐到 3.14.3。本次两件事：把「无限四代」内核**内置进安装包**（开箱即用，不用再手工装插件），并补齐官方「限时可领取体验套餐」链路（官方发额度时客户端主动提示并可一键领取）。

## 本次更新

### 内置无限四代内核（Infinite Generation Four）

- **随安装包分发**：内核已内置，装完就能用，不再需要把插件目录手工注册到 `plugins.dirs`。
- **注入通道**：上游是 DeepSeek Harness 插件，靠 `ctx.systemPrompt.section` 注入系统提示词；ZCode 没有该 API，等价通道是 hook 协议的 `additionalContext`。载荷本身未改一字。
- **默认单层注入**（约 15.3 KB）。可在插件配置里开 `dual_layer` 对齐上游的 `DUAL_LAYER_INJECTION`；但 ZCode 对单个 hook 有 24000 字符硬上限，双层会超限被静默截断，因此实现里自判长度并退回单层 + 告警，保住内核尾部的收束指令。
- **逃生条款锁**：会话开始时扫描载荷，命中削弱条款（作用域例外/授权前置/拒绝犹豫）即告警。
- 可选 `UserPromptSubmit` 每轮补注（默认关）、压缩后重注（默认开）。

### 限时额度可直接领取

- **新增限时额度领取横幅**：官方发放额度时，对话页顶部显示「限时可领取」提示，点「领取」即完成，不用再进设置页找活动入口。
- **领取走官方 billing 端点**：`/api/v1/zcode-plan/billing/preview` 查询可领取套餐，`/api/v1/zcode-plan/billing/claim` 领取；请求头与官方客户端一致（应用版本、平台、验证码参数）。
- **关闭前二次确认**：点关闭会提示「您将错过一次领取机会」，与官方行为一致，避免误关后错过额度。
- **验证码复用现有实现**：直接使用 Start Plan 已有的阿里云验证码流程，不额外引入新组件。
- **领取结果明确**：成功显示套餐与生效时间；失败按原因区分（已领取 / 名额用完 / 需登录 / 版本不符 / 验证码失败等），不再只给一句「失败」。
- **版本动态实时监测**：设置页的官方版本区域现在会自动定时检查，更新内容按条目结构化展示，有新版时高亮提示；仍支持手动刷新。
- **版本号对齐官方 3.14.3**：此前自增的补丁号不再使用，避免与官方版本混淆。
