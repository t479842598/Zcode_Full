# Zcode_满血_青棠 v3.16.2 — 官方 3.16.2 基座同步 + 定制全量重放 + 注入清除

官方仓库在开源后重写过历史：`origin/main` 与我们的 `selfhost-release` **没有共同祖先**
（`git merge-base` 为空）。所以本轮不做 merge/rebase，而是以官方 `3c5b2276`（package.json 3.16.2）
为新基线，把我们相对 `v3.14.3` 的定制差集**逐文件重放**上去。

## 一、同步方式与规模

| 项 | 数量 |
| --- | --- |
| 定制差集文件（`git diff --name-only v3.14.3 84eb8fc2`） | 207 |
| 官方无此路径（直接落地我们的新增文件） | 122 |
| 三方合并干净（`git merge-file` 零冲突） | 45 |

  `ui/src/SettingsPage.tsx`(3)、`services/src/zcode-agent/zcodeAgentService.ts`(3)。

  重放后 `pnpm install --frozen-lockfile` 直接通过（777 包）。
- 官方重写过的段落一律**官方为底、我们的净改动叠加**，不整文件照抄旧版：

  `desktop/src/main/appARMSBootstrap.ts`、`desktop/src/main/remoteCdn.ts`。

  `services/src/project-storage/startup.ts`（`TaskIndexRepo` 构造函数新增 `settings` 参数）；
  我们那个旧路径的文件不再被任何源码引用，**删除**，并把我们在 finally 块里的关闭异常处理
  移植进官方新文件。

## 二、保留的定制能力（本轮全部重放）

**新增能力**

- **自建中继与移动端远控**：`desktop/src/host/relay*.ts`、`services/src/webRemoteControl/`、
  `ui/src/WebRemoteControlDialog.tsx`；侧边栏底部入口由官方闭源 trigger 换成本地按钮
  （`data-testid="web-remote-control-button"`）。
- **自助备份**：`services/src/selfBackup/`、`ui/src/settings/BackupSettingsSection.tsx`；
  协议字段 `selfBackup`（OSS + 加密 + 调度 + 过滤器），秘密字段不落盘、走 `credentialService`。
- **自建自动更新**：`scripts/publish-release.mjs` + `.github/workflows/build-installers.yml`；
  未签名 macOS 构建走自研下载器/安装器（`macosManualUpdateDownloader` / `macosManualUpdateInstaller`），
  绕开 Squirrel 的签名校验；更新源 `ZCODE_SELFHOST_UPDATE_ORIGIN`（默认 `https://zcode.tang74.top`）。
- **自定义供应商「获取模型」**：`services/src/model-provider/providerModelCatalog.ts` +
  `ProviderModelCatalogDialog.tsx`。

**行为调整**

- 去除强制登录；模型出口可自托管（`ZCODE_DISABLE_OFFICIAL_CODING_PLAN_GATEWAY=1`）。
- **关遥测换了实现方式**：官方 3.16.2 新增 `scripts/build-time-config.mjs`，把
  ARMS / telemetry endpoint / 自动更新做成**构建期注入**（不注入即关闭）。我们原来的
  `ZCODE_TELEMETRY_ENABLED` 变量与相关导出**整体丢弃**，避免留下无消费者的死导出。
- 去商业化：删 `handleOpenCodingPlanUpgradeSettings` / 侧边栏升级入口 / 营销外链，
  但**保留官方免费额度 StartPlan 入口**（`OfficialReleaseSection` + `OfficialRewardsSection`）。
- 保留 StartPlan **免验证码**领取链路（官方 3.15.1 起删掉了整个 captcha 子系统，由我们移植保留）：
  `manualClaimPlan.ts` / `startPlanVerification.ts` / `ui/src/root/useStartPlanVerification.ts`；
  官方 3.16.2 内置的通用领取路径（`MarketingTouchProvider`）与本能力共存。
- 思考块不自动收起；移动端适配；任务状态残留清理（`taskIndexRepo` 启动时清 orphan running）。
- 版本号：必须用 `-selfhost.N` prerelease（`+selfhost.N` 不参与 semver 比较，更新推不出去）；
  对外上报统一走 `ZCODE_REPORT_VERSION`（`shared/src/version.ts` 剥离后缀）。
