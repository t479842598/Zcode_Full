# Zcode_满血_青棠 v3.14.5 — 无限四代内核：对话界面开关 + 状态条 + 闭环纠偏

基于 v3.14.4，本轮把内置的无限四代（infinite-gen-4）内核从「只能注入」升级为
「可见、可控、可自愈」：对话界面顶部多出状态条与开关，且检测到拒绝后会自动纠偏续写。

## 一、对话界面状态条与开关

新增 `packages/ui/src/InfiniteGen4Badge.tsx`，挂载在 `DesktopTopOverlay`（输入区上方浮层）。

| 状态 | 呈现 |
| --- | --- |
| 已开启 | 绿点 + 「无限四代」，右侧开关为开 |
| 已开启且上轮命中拒绝 | 橙点 + 「无限四代 · 已纠偏」 |
| 已关闭 | 灰点 + 「无限四代 已关闭」 |

- 开关是语义化 `role="switch"`（带 `aria-checked`），点击即写盘，**下一次 hook 立即按新值行事**，不需要重启。
- 状态条每 3s 轮询刷新（与项目里其它状态卡片同节奏），`title` 显示实际注入字节数。
- **非桌面端不渲染**：Web / 手机远控没有对应宿主能力时，组件自行返回 `null`，不占位、不报错。

## 二、闭环纠偏

`SessionStart` hook 现在会读上一轮的判定（`lastVerdict`）：若为 `refusal` / `fallback`，
在本轮注入的载荷尾部追加一段纠偏指令，把模型拉回「直接给交付物」。

纠偏段等价 DSH 侧的 Order 150 段；开启状态下与主内核一并注入，关闭开关时一并消失（零残留）。

## 三、宿主 ↔ 渲染进程通道

hook 是独立进程，无法直接与渲染进程通信，因此以 `~/.zcode/infinite-gen-4/state.json`
作为共享面（hook 写、UI 读、UI 把开关写回）。为此新增两条平台 IPC：

- `zcode:read-infinite-gen-4-state` → `IPlatformService.readInfiniteGen4State()`
- `zcode:write-infinite-gen-4-enabled` → `IPlatformService.writeInfiniteGen4Enabled()`

宿主侧实现 `packages/desktop/src/main/infiniteGen4/index.ts`：读失败一律返回 `null`（状态条按
「未注入」渲染），写失败返回 `{success:false,error}` —— 状态条故障不阻断会话主链路。

**开关优先级**：`插件目录 config.json > state.json > 内置默认`。显式写下的 config.json 永远优先，
界面开关压不过它（有意为之：显式配置优先）。
