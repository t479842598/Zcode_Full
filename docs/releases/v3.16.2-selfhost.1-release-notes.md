ZCode 自托管版 v3.16.2-selfhost.1 —— 基座同步到官方 3.16.2，定制能力全量重放，注入提示词全部清除。

**同步方式**

- 官方开源后重写过历史，`origin/main` 与我们的旧分支没有共同祖先，所以不做 merge，改为以官方 3.16.2（`3c5b2276`）为新基线逐文件重放定制差集。
- 定制差集 207 个文件：122 个官方无此路径直接落地、45 个零冲突合并、40 个手工合并（73 个冲突块）。
- 官方重写过的段落一律「官方为底 + 我们的净改动叠加」，不整文件照抄旧版。
- 锁文件整体取官方，`pnpm install --frozen-lockfile` 直接通过（777 包）。

**保留的定制能力**

- 自建中继与移动端远控：`desktop/src/host/relay*.ts`、`services/src/webRemoteControl/`、`ui/src/WebRemoteControlDialog.tsx`；侧边栏入口是本地按钮（`data-testid="web-remote-control-button"`），不再是官方闭源 trigger。
- 自助备份：`services/src/selfBackup/`、`ui/src/settings/BackupSettingsSection.tsx`；协议字段 `selfBackup`（OSS + 加密 + 调度 + 过滤器），秘密字段不落盘、走 `credentialService`。
- 自建自动更新：未签名 macOS 构建走自研下载器/安装器，绕开 Squirrel 签名校验；更新源默认 `https://zcode.tang74.top`。
- 自定义供应商「获取模型」：`providerModelCatalog.ts` + `ProviderModelCatalogDialog.tsx`。
- 去除强制登录；模型出口可自托管（`ZCODE_DISABLE_OFFICIAL_CODING_PLAN_GATEWAY=1`）。
- 关闭遥测：改用官方 3.16.2 的构建期注入实现（不注入即关闭），我们旧的 `ZCODE_TELEMETRY_ENABLED` 整体丢弃。
- 去商业化：删升级入口与营销外链，但保留官方免费额度 StartPlan 入口。
- 保留 StartPlan 免验证码领取链路（官方 3.15.1 起删掉了整个 captcha 子系统，由我们移植保留）。
- 思考块不自动收起；移动端适配；任务状态残留清理。
- 版本号用 `-selfhost.N` prerelease，对外上报走 `ZCODE_REPORT_VERSION` 剥离后缀。

**注入提示词清除**

- 项目级：仓库 `AGENTS.md`（含注入块）与 `.zcode/`（63 个技能）整体移出，`.gitignore` 恢复原状。
- 仓库内：删除 `dsh-purge-plugin`（`prompts/operator-directive.md`）与 `infinite-gen-4-plugin`（`prompts/kernel.md`、`kernel-flash.md`），并摘除整条宿主/UI/IPC 接线；构建暂存目录里的旧载荷一并清掉。
- 用户级：`~/.zcode` 下的注入文件全部移出（备份可回滚）。
- 保留 `bundled-skills` 的 24 个内置技能（属功能而非注入）。

**随同步进入的官方新能力**

- `ui/src/project-sidebar/` 重构（项目树取代 workspace tab，归档视图由官方实现）。
